실내외 낙상 예방 5대 안전 수칙

낙상의 60% 이상은 익숙한 집 안에서 발생합니다. 환경을 조금만 바꾸면 안전해집니다.

01

야간 조명 켜두기

밤에 화장실을 갈 때 어두운 상태로 걷지 마세요. 발치등이나 센서등을 침실과 복도, 화장실에 설치하세요.

02

욕실 미끄럼 방지 매트 & 안전 손잡이

물기가 있는 타일 바닥은 매우 미끄럽습니다. 미끄럼 방지 스티커/매트를 부착하고 변기와 샤워기 옆에 손잡이를 설치하세요.

03

미끄럼 방지 양말 & 실내화 착용

맨발이나 미끄러운 일반 양말 대신, 바닥에 고무 패드가 있는 미끄럼 방지 양말이나 뒤축이 감싸진 실내화를 신으세요.

04

바닥 장애물 정리 (전선, 문턱, 발판매트)

발에 걸릴 수 있는 전선, 얇은 카펫, 문턱 등은 테이프로 고정하거나 치워두세요. 이동 동선을 항상 깔끔하게 유지합니다.

05

일어날 때 30초 여유 두기

누워 있거나 앉아 있다가 갑자기 일어나면 기립성 저혈압으로 어지러울 수 있습니다. 일어난 뒤 30초간 가만히 심호흡 후 걸으세요.

Supabase 데이터베이스 연동

클라우드 DB를 연결하면 다른 기기에서도 운동 기록과 출석 현황이 안전하게 보존됩니다.

Supabase 대시보드 -> Project Settings -> API 에서 확인 가능
공개 가능한 anon public API 키를 입력해 주세요.

💡 아직 테이블을 만들지 않으셨나요? 프로젝트의 supabase_setup.sql 파일을 Supabase SQL Editor에 복사하여 실행하시면 즉시 준비됩니다.
