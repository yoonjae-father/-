## 🌟 주요 핵심 기능

### 1. 3대 부위별 맞춤 운동 프로그램 (총 12개 동작)
운동 부위에 따라 꼭 필요한 근력과 유연성, 균형 감각을 체계적으로 단련합니다.

| 카테고리 | 주요 목표 | 포함된 운동 동작 (총 4개씩) |
| :--- | :--- | :--- |
| **💪 상지(상체) 부분** | 낙상 시 손 짚는 지지력 확보 & 악력 및 척추 유연성 | ① 벽 짚고 팔굽혀펴기<br>② 앉아서 양팔 벌려 가슴 펴기<br>③ 어깨 으쓱으쓱 및 회전<br>④ 잼잼 악력 기르기 & 손목 돌리기 |
| **🦵 하지(하체) 부분** | 넘어짐 방지 핵심 근력 & 발목 지지력 및 보행 안정성 | ① 의자 잡고 까치발 들기<br>② 의자 앉았다 일어서기 (미니 스쿼트)<br>③ 의자 잡고 다리 옆으로 들기 (중둔근)<br>④ 발목 까딱까딱 펌프 운동 |
| **🏃‍♂️ 전신 & 균형 부분** | 돌발적인 휘청거림 회복 & 고유수용성 감각 훈련 | ① 한 발로 서서 버티기 (외발 서기)<br>② 발뒤꿈치-발가락 일자 걷기 (탠덤 보행)<br>③ 제자리 무릎 높여 천천히 걷기<br>④ 좌우 무게중심 이동하기 (체중 시프팅) |

### 2. 📺 각 운동별 유튜브(YouTube) 영상 인앱 시청
- 각 운동 카드마다 **[유튜브 영상 보기]** 버튼을 제공합니다.
- 화면 전환이나 외부 앱 이동 없이 웹앱 내부의 **반응형 팝업 플레이어(YouTube Embed)**로 바로 시청할 수 있습니다.
- 큰 화면 시청을 위한 **[유튜브에서 크게 보기]** 새 창 링크와, 영상 시청 후 즉시 타이머로 넘어가는 **[이 운동 타이머로 따라하기]** 버튼을 연동했습니다.

---

### 3. ⏱️ 스마트 코칭 타이머 & 한국어 음성 안내 (TTS)
- **원형 카운트다운 타이머**: 동작별 30초 진행 상태를 시각적 게이지로 한눈에 확인.
- **자동 휴식 간격**: 동작 완료 후 5초간 가벼운 호흡 및 휴식 시간을 자동으로 제공.
- **한국어 음성 가이드 (Web Speech API)**: "운동을 시작합니다", "10초 남았습니다", "동작 완료!" 등 어르신의 눈높이에 맞춘 음성 안내.
- **효과음 안내 (Web Audio API)**: 시작 신호음, 마지막 3초 카운트다운 비프음, 전체 완료 축하 팡파레 제공.

---

### 4. 👓 시니어 친화적 직관적 UI & 접근성
- **글자 크기 3단계 조절**: [보통 / 크게 / 아주 크게] 버튼으로 시력에 맞게 즉시 전환 (설정값 자동 저장).
- **고대비 디자인 & 대형 버튼**: 명확한 컬러 구분과 터치하기 쉬운 큼직한 버튼 크기 적용.
- **직관적인 SVG 모션 일러스트**: 동작마다 움직임 방향과 주의사항을 한눈에 알 수 있는 벡터 그래픽 카드 제공.

---

### 5. 📋 낙상 위험도 자가진단 (CDC STEADI & 보건복지부 기준)
- 5가지 필수 설문을 통해 현재 위험도(**안전** / **주의** / **경고**)를 즉시 평가합니다.
- 진단 결과에 맞춘 단계별 실천 가이드 및 권장 운동 코스를 안내합니다.

---

### 6. 📅 매일 운동 출석 달력 & 통계
- 운동을 완료하면 브라우저(LocalStorage)에 자동으로 출석 도장이 찍힙니다.
- **연속 실천일(스트릭)**, **이번 달 완료 횟수**, **누적 운동 시간**을 한눈에 파악하여 동기를 부여합니다.

---

### 7. 🛡️ 실내외 낙상 예방 5대 생활 안전 수칙
1. **야간 조명 켜두기**: 침실과 복도, 화장실에 발치 센서등 설치
2. **욕실 미끄럼 방지 매트 & 안전 손잡이**: 타일 바닥 미끄럼 방지 및 지지대 설치
3. **미끄럼 방지 양말 & 실내화 착용**: 바닥 고무 패드 양말 착용
4. **바닥 장애물 정리**: 전선, 얇은 매트, 문턱 등 이동 동선 확보
5. **일어날 때 30초 여유 두기**: 기립성 저혈압 어지럼증 방지 심호흡

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: HTML5, CSS3, Modern JavaScript (Vanilla ES6+)
- **Font & Icons**: Pretendard Variable, Font Awesome 6
- **APIs & Features**:
  - Web Speech API (`SpeechSynthesis`) - 한국어 음성 코칭
  - Web Audio API (`AudioContext`) - 타이머 비프음 & 완료 효과음
  - Web Storage API (`localStorage`) - 폰트 설정 및 운동 기록 영구 보존
  - YouTube IFrame Player API / Embed - 고화질 운동 영상 스트리밍
- **Deployment**: GitHub Pages

## 💻 로컬 실행 방법

별도의 서버나 패키지 설치(`npm install` 등)가 전혀 필요하지 않습니다.

1. 저장소를 클론(Clone)하거나 다운로드합니다.
   ```bash
   git clone https://github.com/yoonjae-father/-.git
   ```
2. 폴더 내의 `index.html` 파일을 더블 클릭하여 크롬(Chrome) 또는 엣지(Edge) 브라우저로 열면 즉시 실행됩니다.
